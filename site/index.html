Getting Started with DiskScope

Windows Disk Analysis & Storage Visualization

What is DiskScope?

DiskScope is a dedicated Windows desktop storage diagnostic and cleanup utility. It combines multi-threaded filesystem traversal with an embedded SQLite catalog to index millions of files rapidly while maintaining near-zero CPU and memory overhead.

First Scan Walkthrough

  1. Launch DiskScope.exe: Run the standalone binary or launch from the Start Menu.
  2. Select Target Drives: In the top drive selection combo, choose the drive volume (e.g. C:\) or specific directory tree you wish to analyze.
  3. Click Start Scan: The traversal engine will begin indexing file records into the local SQLite database at rates exceeding 50,000 files/sec on NVMe storage.
  4. Inspect Ingestion Ticker: Real-time statistics will display indexed count, current scan path, and aggregated storage consumption.

Understanding Disk Usage

DiskScope categorizes file items across multiple dimensions:

  • Spatial Treemap: Uses the Squarified Bruls-Huizing layout algorithm to render nested rectangular tiles representing relative folder and file footprints.
  • Category Breakdown: Groups storage into Video Renders, RAW Images, Photoshop Projects (.psd/.psb), Source Code, and Build Caches.
  • Duplicates: Groups files with identical cryptographic SHA-256 digests.

Reviewing Files Before Deletion & Safe Cleanup

CRITICAL SAFETY RULE: DiskScope never performs background or automatic deletions. Every file removal operation must be explicitly confirmed by you. Always verify target paths before clicking "Purge Selected Items".

The Junk Cleaner isolates temporary build caches (node_modules, .gradle, .cargo) and system temp paths. Files locked by active processes are automatically detected and skipped to preserve system stability.

User Guide & Core Features

Spatial Analysis, Deduplication, and Junk Cleaner

Interactive Treemap Navigation

The Squarified Treemap geometry visually represents disk space as proportional rectangles.

  • Left-Click Folder Tile: Drills down into that subfolder tree with animated breadcrumb navigation.
  • Right-Click File Tile: Opens the native Windows context menu ("Open in File Explorer", "Copy File Path").
  • Hover: Displays exact file size, extension, and last modification date in the HUD tooltip.

3-Stage Cryptographic Deduplication

To prevent false positives without wasting I/O bandwidth, duplicate identification follows a strictly phased pipeline:

  1. Stage 1 (Exact Length Matching): Files of unique byte lengths are immediately pruned from candidate sets.
  2. Stage 2 (Header Verification): The first 4,096 bytes are read and compared. Files with differing headers are discarded.
  3. Stage 3 (Full Streaming SHA-256 Digest): Remaining candidates are hashed via a memory-bounded SHA-256 stream to confirm bit-for-bit equality.

Developer Junk Cleaner

Scans known ephemeral compiler caches:

  • node_modules (JavaScript / TypeScript npm and yarn dependencies)
  • .gradle\caches (Android / Java build outputs)
  • .cargo\registry (Rust package build artifacts)
  • %LocalAppData%\Temp & C:\Windows\Temp (System user temp files)

Security & Permissions

Windows Security Model, Privileges, and Isolation

Standard User Context (No Elevation Required)

DiskScope executes natively under the privileges of the active logged-in Windows user account. It does not require UAC Administrator elevation to run or analyze user drives.

Handling Protected System Paths

When scanning drives that contain protected operating system directories (e.g. C:\Windows\System32, System Volume Information), Windows NTFS Access Control Lists (ACLs) prevent standard users from reading certain metadata. DiskScope safely catches UnauthorizedAccessException and skips those nodes without crashing or hanging.

Strict Offline Architecture

DiskScope is fully local:

  • Zero Network Calls: The desktop executable contains zero HTTP, socket, or cloud synchronization code.
  • Zero Telemetry: No analytics, crash telemetries, or usage statistics are ever collected or transmitted.
  • File Isolation: File contents are never uploaded or read beyond the streaming byte windows required for deduplication.

Troubleshooting Guide

Common Questions, Warnings, and Solutions

"Windows protected your PC" (Microsoft Defender SmartScreen)

When executing newly downloaded standalone executables that are not digitally code-signed with an expensive commercial EV certificate, Windows Defender SmartScreen may display an informational dialog.

To proceed: Click "More info" followed by "Run anyway". You can verify binary authenticity anytime by checking the published SHA-256 hash.

Locked Files During Cleanup

If the Junk Cleaner displays a warning that a file could not be deleted, the file is currently open and locked by another Windows process (e.g., Chrome cache, running node service). DiskScope automatically skips locked files to avoid corrupting running processes.

Resetting the Local SQLite Index

If you ever wish to completely clear your indexed file records and start from scratch, close DiskScope and delete the database file located at:

%LocalAppData%\DiskScope\scan_index.db

Uninstallation & Data Removal

Clean System Removal Procedures

Portable Executable Removal

If you ran DiskScope as a standalone portable binary, simply delete DiskScope.exe. The binary creates zero registry keys and zero system driver hooks.

Purging Cached Application Data

DiskScope stores its SQLite catalog database in the user profile directory. To completely remove all associated data, delete the directory:

%LocalAppData%\DiskScope

Once this folder is deleted, zero residual files, indices, or logs remain on the machine.

Windows Setup Uninstaller

If installed via the Inno Setup installer package, open Windows Settings > Apps > Installed Apps, locate DiskScope, and click Uninstall. The uninstaller will cleanly remove program files and shortcuts.
