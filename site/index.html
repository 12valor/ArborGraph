Getting Started with DiskScope

Document ID: DS-DOC-001 • Version 1.0

What is DiskScope?

DiskScope is an offline Windows desktop utility designed for rapid disk analysis, visual storage breakdown, and safe developer junk cleanup on 64-bit Windows machines.

First Scan Workflow

  1. Launch the Application: Double-click DiskScope.exe. The executable runs natively without external runtime installers.
  2. Select Target Volume: Choose your system drive (e.g., C:\) or secondary development volume from the top drive dropdown.
  3. Execute Scan: Click Start Scan. The bounded multi-threaded traversal engine immediately crawls the directory hierarchy, indexing file attributes into a local SQLite database in WAL mode.
  4. Review Disk Consumption: Inspect the Treemap view to locate oversized directories, video caches, RAW camera files, or large Photoshop assets.
NOTE: The scan index is stored exclusively on your local computer at %LocalAppData%\DiskScope\scan_index.db. No filesystem paths or file contents are ever transmitted across networks.

User Guide & Core Features

Document ID: DS-DOC-003 • Version 1.0

Squarified Treemap Navigation

The Treemap visualizer renders filesystem directories as nested rectangles utilizing the Bruls-Huizing layout algorithm. Rectangle area is proportional to byte consumption. Double-clicking any directory card drills down into its subtree with a breadcrumb trail for navigation.

Cryptographic Deduplication

DiskScope employs a 3-stage validation pipeline to detect duplicate files without false positives:

  • Stage 1 (Length Grouping): Fast SQL grouping by identical byte sizes.
  • Stage 2 (Header Check): Reads initial 4 KB blocks to eliminate size collisions.
  • Stage 3 (SHA-256 Digest): Full cryptographic block hash computed via streaming memory channels.

Developer Junk Cleaner

Targeted discovery of orphaned build artifacts (node_modules, .gradle/caches, .cargo/registry, bin/obj). In-use files are skipped safely without terminating batch operations.

Security & Permissions

Document ID: DS-DOC-006 • Version 1.0

Standard User Privileges

DiskScope does not require administrative elevation (UAC prompt) for scanning standard user profiles, documents, code directories, and secondary drives.

Locked Files & Access Control Lists

Files locked by other running processes or restricted by NTFS permissions are logged as skipped items without throwing unhandled exceptions.

ZERO NETWORK TELEMETRY: DiskScope has no outbound network communication, analytics endpoints, or cloud synchronizers.

Troubleshooting Guide

Document ID: DS-DOC-007 • Version 1.0

Windows Defender SmartScreen Prompt

Notice: When launching a freshly downloaded binary, Windows SmartScreen may display: "Windows protected your PC".

To proceed, click "More info" and select "Run anyway". You can verify the official SHA-256 hash using the Package Verification tab to ensure the binary is unaltered.

Resetting Local Database Index

If the SQLite index becomes locked or you wish to start fresh, delete the file %LocalAppData%\DiskScope\scan_index.db. The application will regenerate the database automatically on the next run.

Uninstallation & Data Removal

Document ID: DS-DOC-008 • Version 1.0

Complete Application Removal

  1. Portable Binary: Delete DiskScope.exe from your chosen folder.
  2. Installed Version: Open Windows Settings > Apps > Installed Apps, locate DiskScope, and select Uninstall.
  3. Purge Local Catalog Data: Delete the local application directory:
    Remove-Item -Recurse "$env:LOCALAPPDATA\DiskScope"
