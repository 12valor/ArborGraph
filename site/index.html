See the shape of your storage.

Every rectangle surface area directly corresponds to its indexed logical bytes. ArborGraph computes squarified treemap tessellations so runaway directories become instantly visible without manual traversal.

  • Proportional geometry: Larger rectangular blocks denote larger disk consumers at a glance.
  • Hierarchical drill-down: Click any directory block to isolate and inspect its internal child hierarchy.
  • Stable aspect ratios: The squarified algorithm avoids long, thin slivers, keeping file labels legible.

Inspect candidates without deleting.

Review duplicate candidates identified by matching file sizes and verified content hashes. ArborGraph Preview is strictly read-only: files are never removed automatically, protecting your system from accidental data loss.

  • Size and hash verification: Compares candidates using fast progressive hash checks to eliminate false positives.
  • Zero-deletion safety: Scanned files remain untouched; preview insights are strictly diagnostic.
  • Storage estimates: Review duplicate candidates before making personal cleanup decisions. Actual space savings can differ.

Engineered for hardware-level reliability.

Filesystem inspection requires thoughtful I/O orchestration. ArborGraph respects drive mechanics and operating system boundaries to prevent system lag.

Asynchronous Traversal & Sector Awareness

Disk scanning executes in a dedicated .NET background engine utilizing asynchronous file-enumeration APIs. By batching metadata requests, ArborGraph prevents head thrashing on mechanical disks and maximizes throughput on solid-state NVMe drives.

Non-blocking background thread / Multi-drive indexing

Strictly Local Processing & Zero Network I/O

Your filesystem contains sensitive personal documents, financial data, and proprietary source code. ArborGraph makes zero outbound network requests. All paths, file names, and byte counts remain strictly inside your local user profile.

Getting started with ArborGraph.

Essential guidance for installation, scanning large storage volumes, and managing local catalogs.

Installation & Setup

Download the x64 setup wizard, confirm the SHA-256 checksum, and run the installer. The wizard configures desktop shortcuts and registers the uninstaller in Windows Settings.

System Requirements

Windows 10 or Windows 11 on an x64 processor. The preview bundles all necessary runtime dependencies. Works with NTFS, FAT32, exFAT, and mounted external drives.

Running Your First Scan

Launch ArborGraph Desktop, pick a drive letter or click Choose Folder, then click Start Scan. Once complete, browse treemap blocks and file categories.

SmartScreen & Permissions

Because ArborGraph is independently published, Windows SmartScreen may present a notice. You can verify the hash matches our published release. Scanning locked system files reports them safely as skipped.

Scan History & Cache

Scans are indexed into your local user application data. You can reopen earlier scans to compare drive usage or clear database history anytime from the application settings.

Clean Uninstallation

Remove ArborGraph via Windows Settings → Installed Apps. Your scanned drives are untouched. The local SQLite catalog can be kept for future installations or purged.
