Core Functionality

1. SQLite-Indexed File Ingestion

Scans multi-terabyte drives with bounded 20,000-item channels and deferred secondary indexing, persisting into an embedded WAL database without UI thread stutter.

2. Squarified Space Treemap

Visualizes directory space consumption via the Bruls-Huizing-van Wijk algorithm. Supports interactive folder drilldown, breadcrumb navigation, and direct Explorer access.

3. Developer & System Junk Cleaner

Safely purges abandoned node_modules, .gradle, .cargo, browser caches, and Windows temp files with automatic locked-file skip protection.

4. Cryptographic Deduplication & Reports

Detects identical files using a zero-false-positive 3-tier hash pipeline. Exports standalone dark-mode HTML reports, CSVs, or machine-readable JSON dumps.
